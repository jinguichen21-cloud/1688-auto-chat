# 1688-auto-chat Skill

##功能说明

自动化与1688商家沟通，获取以下4项核心信息并回写钉钉表格：
1.现货情况（颜色/库存状态）
2.是否可贴条码/贴牌
3.包装尺寸（长×宽×高 cm）
4.包装重量（g/kg）

## 使用场景

-跨境电商选品时批量询问供应商
-自动跟进1688同款商品的详细信息
-将沟通结果结构化存储到钉钉 AI 表格

- **结构化记录** (`O41WlpD`): JSON格式的结构化数据

##工作流程

1. **读取表格** → 筛选有商品链接但未沟通的记录
2. **打开商品页** → 通过浏览器自动化访问1688 商品详情
3. **唤起旺旺** → 点击客服按钮，激活聊天会话
4. **发送商品卡片** → 点击`.odDetail-sendBtn`发送商品链接卡片
5. **发送询问** → 发送标准化询问文本（4项核心问题）
6. **监控回复** → 实时监听商家回复，用正则提取关键信息
7. **智能追问** → 信息缺失时针对性追问（最多2次）
8. **回写结果** → 将提取的信息回写钉钉表格

## 技术特点

- **混合消息发送方案**:浏览器导航 + 系统级UI 模拟，绕过React/Vue框架限制
- **智能正则提取**:自动识别中文数字、单位变体（cm/厘米、kg/千克等）
- **并行处理**:支持多线程同时沟通多个商家，提升效率
- **容错机制**:链接失效、超时未回复、提取失败等情况的优雅处理

## 常见问题

**Q:为什么消息发送失败？**  
A:旺旺前端使用React/Vue框架，直接DOM 操作无效。本技能已通过evaluate注入事件的方式解决。

**Q:商家一直不回复怎么办？**  
A:默认超时3分钟，标记为"商家未回复"。可稍后重试或手动联系。

**Q:如何修改询问话术？**  
A:在SKILL.md的`核心工作流`部分修改`inquiry_text`参数。

**Q:可以自定义提取规则吗？**  
A:可以，在`monitor_merchant_reply`的`extraction_rules`参数中调整正则表达式。
